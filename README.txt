DEEP MORNING HELP CENTER — UPLOAD GUIDE
========================================

This folder contains:
- index.html (Help Center home)
- support.html (contact support)
- focus-sessions.html
- calendar-connections.html
- focus-protection.html
- account-profile.html
- community.html
- styles.css (shared styling)

IMPORTANT: This package is designed to be ADDED to your existing site.
Keep these files from your current website exactly where they are:
- privacy.html (your working Privacy Policy)
- assets/deep-morning-icon.png (your existing official app icon)

Deployment:
1. Back up your current site.
2. Upload the 7 HTML files and styles.css into the SAME public directory
   as your current index.html, replacing the old index.html.
3. Do NOT delete the existing assets/ directory or privacy.html.
4. Confirm each of these URLs works (replace YOURDOMAIN):
   https://YOURDOMAIN/index.html
   https://YOURDOMAIN/support.html
   https://YOURDOMAIN/focus-sessions.html
   https://YOURDOMAIN/calendar-connections.html
   https://YOURDOMAIN/focus-protection.html
   https://YOURDOMAIN/account-profile.html
   https://YOURDOMAIN/community.html
   https://YOURDOMAIN/privacy.html
5. Test navigation and mail links on a mobile device.

The site is plain HTML and CSS. It requires no JavaScript, backend,
framework, paid service, or additional dependencies.

Apple App Store Connect:
- Use the publicly accessible Help Center URL (or /support.html) as Support URL.
- Use the existing /privacy.html URL as Privacy Policy URL.

Notes:
- The help article wording is starter copy based on the provided app
  description. Verify the menu names and feature availability against
  the exact App Store build before publishing.
- The files intentionally reuse your existing app icon path; no replacement
  image is included.
- The contact email is liverdom@icloud.com as in the supplied page.
